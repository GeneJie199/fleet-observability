# Product and commercialization boundary

| Offering | Scope |
|---|---|
| Community | AGPL-3.0-only; complete existing DevCycle, InfraScout, FleetScope, ReleaseGuard, lifecycle, installer/offline and verification capabilities |
| Enterprise | Future SSO/LDAP, advanced RBAC, organization/audit/governance, HA, compliance, enterprise AI/model policy and large-scale operations |
| OEM | Negotiated closed-source customization, embedded distribution, rebranding, white-labeling, downstream resale and customer delivery |
| Cloud | Future managed hosting with separately agreed operation/support terms; no billing backend in this milestone |
| Services | Private deployment, integration, customization, consulting and support by agreement |

Enterprise extensions depend on public capability/adapter/entitlement contracts.
Community does not import Enterprise and runs without a license server, forced online
activation, telemetry lock or DRM. Existing v1 features are not removed or paywalled.
An entitlement interface is an extension boundary, not a Community startup gate.
Future proprietary plugins require a legal combined-work analysis or appropriate
commercial grant; a technical plugin boundary alone does not settle license questions.
